关于校园二手交易平台

项目简介

校园二手交易平台是本小组课程设计作品，面向在校大学生，用于校内闲置物品流转，减少资源浪费，实现低碳校园。学生可以浏览闲置商品，查看详情，发布自己的二手物品。本网站为静态网页，仅用于课程演示。

开发技术

HTML5 + CSS3 + JavaScript + Bootstrap5

小组成员

  • 成员A：页面原型、文档撰写
  • 成员B：首页、商品列表页面开发
  • 成员C：详情页、发布表单页面开发
  • 成员D：JS交互、网站部署，获取项目网址

网站功能

  1. 首页展示商品分类与推荐闲置
  2. 商品列表，支持搜索和分类筛选
  3. 商品详情查看
  4. 闲置物品发布表单（前端校验）
